# Syntax — синтаксис TypeScript

Поле для **экспериментов** и **мини-заданий** по [syntax-plan.md](../../../../syntax-plan.md).

План модулей: **S01–S15**. Книга (62 правила) — отдельно в `labs/ts-NN/`.

---

## Файлы

| Файл | Назначение |
|------|------------|
| [`lesson.ts`](lesson.ts) | Текущее задание от ментора (меняется по модулю S01…) |
| [`workshop.ts`](workshop.ts) | Твой черновик — пиши что угодно, не трогаем при смене урока |

---

## Как работать

1. В чате: **«синтаксис S01»** — разбор + задание в `lesson.ts`
2. Пишешь код в `runLesson()` / `runWorkshop()` — `console.log` выводится на странице и в DevTools
3. **«проверь S01»** — разбор
4. Ментор отмечает `done` в `syntax-plan.md`

Проверка типов:

```bash
npm run build
```

Или смотри ошибки прямо в IDE.
