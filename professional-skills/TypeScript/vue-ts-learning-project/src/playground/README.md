# Playground

Свободные эксперименты **без** привязки к assignment.

- Создавай файлы `*.ts` здесь.
- Импортируй в `example.ts` или подключи в `App.vue` временно.
- Не коммить мусор — или держи в `.gitignore` локальные `scratch-*.ts` (по желанию).

Пример: скопируй snippet из книги, поиграй с типами, смотри ошибки в IDE и `npm run build`.
