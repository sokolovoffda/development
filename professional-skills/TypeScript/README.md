## Workflow

1. Ты: **«разбираем правило 5»** (или `правило 14`, `ts-14`).
2. Ментор читает правило в книге → создаёт/обновляет `labs/ts-05/`.
3. В `exercises.ts` — заготовка: код с TODO или комментарии (теория).
4. `active.ts` → переключение на нужный lab → `npm run dev`.
5. По желанию: конспект в `notes/`, разбор в чате.

Папки **6–62** появляются по мере прохождения, не все сразу.
