# Assignments

Задания по item'ам книги. Текстовый ответ — в файле; код — в `vue-ts-learning-project/src/labs/`.

## Структура

```text
assignments/
├── README.md
└── phase-N/
    └── NN-short-slug.md
```

Имена: `01-structural-vs-nominal.md` · ID в чате: **TS-01**.

## Формат файла

```markdown
# TS-01 — Short title

| | |
|--|--|
| Phase | 1 |
| Item | 1 |
| Status | todo / in_progress / review / done |

## Task
…

## Your answer
…только ты…

## Mentor feedback
*(ментор)*
```

## Правила

1. Пишешь **только** в `## Your answer` (Status → `review` → «проверь TS-01»).
2. Код — в соответствующей папке `src/labs/ts-NN-…/`.
3. Ментор не правит `## Your answer`; разбор — в `## Mentor feedback`.
4. После разбора: Status `done`, запись в `progress.md`, при необходимости error bank.
5. Перед заданием — конспект в `notes/phase-N/`.

## Статусы

| Status | Значение |
|--------|----------|
| `todo` | выдано |
| `in_progress` | в работе |
| `review` | готово к проверке |
| `done` | разобрано |
