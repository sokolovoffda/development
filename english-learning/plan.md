## Методика

- **CEFR** — уровни и цели.
- **Deliberate practice** — listening/speaking + грамматика в output.
- **Comprehensible input** — чуть на грани уровня, с текстом/субтитрами.
- **Output + corrective feedback** — письмо и ответы в этом чате.
- **Spaced repetition** — Anki только из error bank / chunks фазы.
- **Sentence / chunk learning** — фразы целиком.
- **Новые chunks:** **0–5 в день** (не «слов ради слов»). Остальное время Anki = повтор. 0 новых — нормальный день, если только повторяешь.

## Цель на 6 месяцев (измеримо)

К ~2027-02:

1. Текст о работе 8–12 предложений без системных A2-ошибок (Present Simple, *at work*, a/an, базовые chunks).
2. Чтение адаптированных / коротких tech-абзацев; новые chunks в лимите **0–5/день** (ориентир ~15–25/нед max, без гонки).
3. Listening: суть 1–3 мин A2–B1 (1× + текст).
4. Speaking: 2–3 мин монолога по шаблону в коммьют.
5. Tech EN: короткий фрагмент доков + простой промпт на EN.

## Общий недельный ритм (~7 ч)

| Слот | Длительность | Что делать |
|------|--------------|------------|
| Утро | 15 мин | Anki (повтор) **или** черновик 5–8 предложений |
| Работа / перерыв | 15 мин | Короткий текст; новые chunks только в лимите 0–5/день |
| Вечер | 15–30 мин | 1 грам-тема **или** сессия в чате |
| Коммьют | 10–20 мин | Listening + shadowing / монолог |
| 1× в неделю | 30–40 мин | Итог с ментором |

### Анти-расфокус

1. Одна главная задача на слот.
2. YouTube — только из `resources.md` или согласованный ролик.
3. За 15 мин — один тип работы.
4. В чате: макс. **3 правки** за раз + 1 исправленный абзац.
