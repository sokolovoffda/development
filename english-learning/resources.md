# Resources

Только то, что подходит под A2, короткие сессии и твой запрос «сначала понятно, потом по-английски». Список короткий — меньше расфокуса.

## Core (обязательный минимум)

| Ресурс | Зачем | Как использовать |
|--------|-------|------------------|
| Этот чат (ментор) | Output + разбор ошибок | 1–2 коротких текста / диалога в неделю |
| **Anki** (или Quizlet) | Повтор + немного нового из error bank / текстов | **Новых chunks: 0–5/день.** Повтор: сколько успеваешь за слот (ориентир до ~10–15 карточек всего за день, без выгорания) |
| **British Council — LearnEnglish** (A2 Getting started / Skills) | Проверенный graded контент | 1 навык за сессию |
| **BBC Learning English** — *The English We Speak* / *Express English* (короткие) | Listening + chunks | С транскриптом; shadowing в дороге |

Официальные ориентиры уровней: [CEFR](https://www.coe.int/en/web/common-european-framework-reference-languages) (Council of Europe).

## Билингвально / с опорой на русский

| Ресурс | Зачем | Ограничение |
|--------|-------|-------------|
| **Puzzle English** (разборы) / каналы с RU→EN объяснением грамматики | Как ты просил: сначала по-русски | Выбирать **1 канал** и 1 плейлист A2; не листать рекомендации |
| Ментор в чате | Объяснение правила по-русски → сразу твои фразы на EN | Основной «билингвальный» контур |

Рекомендация: для грамматики Phase 1 чаще опирайся на чат + BC/BBC, а YouTube — max **2 ролика/нед** из заранее выбранного плейлиста (запишем название после Session 1, если пришлёшь 1–2 варианта что смотришь).

## Tech English (лёгкий параллельный трек)

| Ресурс | Когда |
|--------|-------|
| Короткие фрагменты MDN / Vue docs (1 абзац) | С Phase 2; в Phase 1 — только слова из твоего стека в предложениях |
| Свои промпты к AI на EN (3–5 строк) | С недели 3–4, после стабилизации *I want to / I need to* |

## Speaking / commute

1. Прослушай 1–2 мин с текстом.
2. Повтори вслух за диктором (shadowing).
3. Скажи **свой** вариант: *I work as… At work I… My stack is…*

Шаблон монолога (выучи как скелет):

```text
I work as a web developer.
At work I develop software for traders.
My stack is Vue 3, TypeScript, and Pinia.
I need English to read documentation and to travel.
```

## Не использовать как основу

- Бесконечный Duolingo streak без письма/говорения.
- Рандомные «learn English» Shorts.
- Таблицы всех времён сразу.
