# Notes

Конспекты тем и FAQ — **по фазам**.

```text
notes/
├── README.md
├── phase-1/
│   ├── 01-present-simple.md   ← тема
│   ├── faq.md                 ← вопросы из чата (в рамках Phase 1)
│   └── …
├── phase-2/
└── phase-3/
```

## Правила

1. На каждую учебную тему — файл `NN-slug.md` в папке текущей фазы.
2. Ментор пишет note до/вместе с заданием в `assignments/phase-N/`.
3. Вопросы из чата, полезные для фазы → краткая запись в `faq.md` этой фазы (вопрос → ответ).
4. Не тащим сюда материал следующих фаз целиком.
