# Theme 3 — Prepositions (мини-конспект)

Короткий набор для работы и недели. Не все предлоги английского — только частые.

---

## 1. Место / работа — *at / in / on*

| Предлог | Когда | Примеры |
|---------|-------|---------|
| **at** | точка / место деятельности | **at** work, **at** home, **at** the office, **at** Satel |
| **in** | внутри / город / сфера | **in** a bank, **in** the office (внутри здания), **in** Moscow, **in** the team |
| **on** | поверхность / «на» платформе | **on** the desk, **on** the screen, **on** GitHub |

### Под тебя

```text
✓ At work I develop software.
✓ I work in a bank / for traders in banks.
✓ The bug is on the screen.
✗ On work → At work
✗ in work (обычно нет)
```

*at work* = «на работе» (деятельность).  
*in the office* = внутри офиса (здание).

---

## 2. Время — *at / in / on*

| Предлог | Когда | Примеры |
|---------|-------|---------|
| **at** | точное время | **at** 9 o’clock, **at** noon, **at** the moment |
| **on** | дни / даты | **on** Monday, **on** Friday, **on** the weekend* |
| **in** | месяцы / годы / части дня | **in** September, **in** 2026, **in** the morning |

\*US часто *on the weekend*; UK *at the weekend* — оба ок, выбери один и держи.

```text
✓ I work on Monday.
✓ I have a meeting at 10.
✓ We released the feature in August.
✗ in Monday → on Monday
✗ at Monday → on Monday
```

---

## 3. *for / to / with / about*

| Предлог | Смысл | Пример |
|---------|-------|--------|
| **for** | для кого / зачем | apps **for** traders · English **for** work |
| **to** | направление / цель | deploy **to** production · go **to** work |
| **with** | с кем / с чем | work **with** TypeScript · talk **with** Sergey |
| **about** | о чём | a bug **about** login · talk **about** the feature |

```text
✓ I develop an app for traders.     (не for a traders)
✓ She isn’t deploying to production.
✓ I work with Vue and Pinia.
✓ We talk about the requirements.
```

## 5. Ловушки из твоих текстов

| Неверно | Верно |
|---------|--------|
| On work | **At** work |
| for a traders / for a banks | for **traders** / for **banks** |
| on the production | **to** production |
| work at many time | work **a lot** / for **many hours** |
| in Monday | **on** Monday |

---

## 6. Мини-текст

```text
I work at Satel. At work I develop apps for traders in banks.
On Monday I usually have a stand-up at 10.
Today I’m working on a bug about the contact card.
We don’t deploy to production on Friday.
```
