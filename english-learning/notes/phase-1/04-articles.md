# Theme 4 — Articles (a / an / the)

Три варианта: **a / an** (неопределённый), **the** (определённый), **∅** (без артикля).

---

## 1. *a / an* — «один из», впервые, неизвестный читателю

Перед **единственным числом** (одна штука, неизвестная или одна из многих).

- **a** — перед согласным звуком: **a** developer, **a** bug, **a** bank, **a** plan, **a** feature
- **an** — перед гласным звуком: **an** app, **an** engineer, **an** error, **an** issue, **an** hour

**Когда:**
- первое упоминание: *I found **a** bug.*
- профессия / роль: *I am **a** developer.* *He is **a** team lead.*
- «один из»: *We have **a** meeting on Monday.*

```text
✓ I am a developer.
✓ I found an error.
✓ He is a team lead.
✗ I am developer.    ← нет артикля перед профессией
✗ I found a errors.  ← a + мн.ч. = нельзя
```

---

## 2. *the* — «тот самый», конкретный, уже известный

Перед единственным и множественным числом, когда понятно **какой именно**.

- второе упоминание: *I found a bug. **The** bug is in the login page.*
- единственный в своём роде: ***the** office* (наш офис), ***the** production server*
- оба знают, о чём речь: ***the** team*, ***the** project*, ***the** screen*

```text
✓ I'm working on the contact card feature.   ← конкретная фича
✓ The bug is on the login page.              ← тот самый баг
✓ We deploy to the production server.        ← конкретный сервер
```

---

## 3. ∅ — без артикля

- **Множественное число** в общем смысле: *I develop apps for **traders**.* (все трейдеры вообще)
- **Неисчисляемые** существительные: *documentation, software, work, English, music*
- **Имена собственные:** *Satel, Vue, TypeScript, Monday, Moscow*
- Устойчивые сочетания: *at work* (не *at the work*), *go home* (не *to the home*), *deploy to production* (не *to the production* чаще)

```text
✓ I develop software for banks.         ← мн.ч. вообще
✓ I read documentation.                 ← неисчисляемое
✓ At work I use TypeScript.             ← at work без the
✗ I develop softwares.                  ← software не мн.ч.
✗ I read a documentation.               ← неисчисляемое без a
```

---

## 4. Частые пары (запомни)

| ✗ Неверно | ✓ Верно |
|-----------|---------|
| I am developer | I am **a** developer |
| I found a errors | I found **errors** / **an** error |
| The English is important | **English** is important |
| I develop a software | I develop **software** |
| for a traders | for **traders** |
| for a banks | for **banks** |
| I go to the home | I go **home** |

---

## 5. Мини-текст

```text
I am a web developer.
I work in a team of five engineers.
At work I develop an app for traders.
I found a bug in the login page.
The bug is in the authentication module.
I don't read a documentation — I read documentation.
English is important for my work.
```
