# Theme 1 — Present Simple (мини-конспект)

Для фактов о работе, привычках, постоянных вещах. Не для «прямо сейчас в эту секунду» (это Continuous — Theme 2).

## Формула

| | Утверждение | Отрицание | Вопрос |
|--|-------------|-----------|--------|
| I / you / we / they | I **work** | I **don’t work** | **Do** you **work**? |
| he / she / it | He **works** | He **doesn’t work** | **Does** he **work**? |

К *he/she/it* у глагола обычно **-s**: *works, develops, needs, wants*.  
Исключения по spelling позже; сейчас важно само **-s**.

Глагол **be** особый: *I **am** / he **is** / they **are*** (не *I be*, не *Do I am*).

## Когда использовать (твои типичные фразы)

- Кто ты по работе: *I **work** as a web developer.*
- Что обычно делаешь: *At work I **develop** software.*
- Стек / факты: *My stack **is** Vue 3 and TypeScript.*
- Нужды / желания (как привычный факт): *I **need** English. I **want** to read docs.*

## Частые маркеры

*every day, usually, often, sometimes, never* — часто с Present Simple.

## Чего пока не делать

| Неверно (из твоего старта) | Верно |
|----------------------------|--------|
| I working | I **work** / I **am** working (второе — Theme 2) |
| i development | I **develop** |
| On work | **At** work |
| My stack it is | My stack **is** |

## Мини-примеры под тебя

```text
I work as a web developer.
At work I develop software for traders.
My stack is Vue 3, TypeScript, and Pinia.
I need English for work.
I want to read technical documentation.
I don’t have a clear goal yet.
```

Следующая тема после закрепления: Present Continuous vs Simple (*I’m working* vs *I work*).
