# Theme 5 — Chunks: *want to / need to / don’t have*

Развёрнутый конспект. Цель: стабильные куски речи без кальки с русского  
(*I want read*, *I want free reading*, *I dont target*).

Связано с ошибками из assessment и P1-CP1: почти всегда нужен **to** перед глаголом.

---

## 0. Зачем эта тема

В русском часто:

- «хочу читать» → кажется *I want read*
- «хочу свободное чтение» → *I want free reading*
- «мне нужен английский» / «мне нужно улучшить» — путаются

В английском:

| Русский смысл | Английский chunk |
|---------------|------------------|
| хочу **сделать** X | **want to + V** |
| нужно **сделать** X | **need to + V** |
| нужен **предмет/ресурс** | **need + noun** |
| у меня нет X | **don’t / doesn’t have + noun** |

---

## 1. *want to + V* — хочу сделать

### Формула

```text
want to + глагол (1-я форма, без -s / -ing / -ed)
```

| Лицо | Утверждение | Отрицание | Вопрос |
|------|-------------|-----------|--------|
| I / you / we / they | I **want to** fix… | I **don’t want to** fix… | **Do** you **want to** fix…? |
| he / she / it | He **wants to** fix… | He **doesn’t want to** fix… | **Does** she **want to** fix…? |

После *want* почти всегда **to**.  
Глагол после *to* — **базовая форма**: *to read, to fix, to deploy* (не *to reads / to fixing*).

### Примеры — работа

```text
I want to read technical documentation.
I want to improve my English.
I want to clarify the requirements.
I want to fix this bug today.

She wants to deploy on Friday.
He wants to review my pull request.

I don’t want to postpone the deadline.
I don’t want to deploy to production now.

Do you want to join the stand-up?
Does he want to prioritize this ticket?
```

### Типичные ошибки

| ✗ | ✓ | Почему |
|---|---|--------|
| I want read | I want **to** read | нужен *to* |
| I want free reading | I want **to read** freely | действие = глагол |
| I want improving | I want **to improve** | не *-ing* после *want to* |
| He want to fix | He **wants** to fix | he → *-s* на *want* |

### Коротко

> *want* = желание · дальше действие → **to + V**

---

## 2. *need to + V* — нужно / необходимо сделать

### Формула

```text
need to + глагол (1-я форма)
```

| Лицо | Утверждение | Отрицание | Вопрос |
|------|-------------|-----------|--------|
| I / you / we / they | I **need to** fix… | I **don’t need to** fix… | **Do** we **need to** fix…? |
| he / she / it | He **needs to** fix… | He **doesn’t need to** fix… | **Does** he **need to** fix…? |

Смысл: не «хочу», а **надо** (работа, дедлайн, правило).

```text
I need to clarify the requirements.
We need to fix this bug before Friday.
He needs to review the code.
I need to improve my English.
I don’t need to deploy today.
Do you need to join the meeting?
```

### *need to + V* vs *need + noun*

Это **два разных** паттерна — не смешивай.

| Нужно **сделать** (глагол) | Нужен **предмет** (существительное) |
|----------------------------|-------------------------------------|
| I need **to** improve my English | I need English |
| I need **to** find a solution | I need a solution |
| We need **to** clarify the requirements | We need clear requirements |
| She needs **to** get access | She needs access |

```text
✓ I need English for work.
✓ I need to learn English for work.
✓ We need a reliable solution.
✓ We need to find a reliable solution.

✗ I need to English.
✗ I need improve my English.
```

### Как выбрать за 2 секунды

1. После *need* идёт **глагол** (делать)? → **need to + V**  
2. После *need* идёт **вещь/человек/ресурс**? → **need + noun** (без *to*)

## 3. *don’t / doesn’t have* — нет чего-то

### Формула

```text
don’t / doesn’t have + существительное
```

| Лицо | Утверждение | Отрицание | Вопрос |
|------|-------------|-----------|--------|
| I / you / we / they | I **have** a ticket | I **don’t have** a ticket | **Do** you **have**…? |
| he / she / it | He **has** access | He **doesn’t have** access | **Does** he **have**…? |

```text
I don’t have much time today.
I don’t have a clear goal yet.
I don’t have a ticket for this bug.
He doesn’t have access to the API.
She doesn’t have enough experience yet.

Do you have a deadline this week?
— Yes, I do. / No, I don’t.
```

### Ловушки

| ✗ | ✓ |
|---|---|
| I dont target | I **don’t have** a (clear) goal |
| I haven’t a goal *(A2)* | I **don’t have** a goal |
| He don’t have access | He **doesn’t have** access |
| I don’t have time much | I don’t have **much** time |

На A2 для «у меня нет» используй **don’t/doesn’t have**, не *haven’t got* (можно позже).

## 4. Все формы рядом (шпаргалка)

```text
I want to + V        I don’t want to + V        Do you want to + V?
He wants to + V      He doesn’t want to + V     Does he want to + V?

I need to + V        I don’t need to + V        Do you need to + V?
He needs to + V      He doesn’t need to + V     Does he need to + V?

I need + noun        (без to)
I have + noun
I don’t have + noun  He doesn’t have + noun
Do you have + noun?
```

---

## 5. Связка с уже пройденным

### Simple vs Continuous + want/need

*want / need* — обычно **Simple** (состояние), не Continuous:

```text
✓ I want to fix this bug.
✗ I am wanting to fix this bug.   ← не для A2

✓ I need to clarify the requirements.
✗ I am needing to clarify…
```

Но действие после *to* может описывать Continuous-ситуацию:

```text
Right now I need to fix a bug.     ← need = Simple; ситуация «сейчас»
Today I want to clarify the API.   ← want = Simple; план на сегодня
```

### Артикли после have/need

```text
I need a solution.          ← один, неизвестный
I need the solution from QA ← конкретный
I don’t have a ticket.
I don’t have much time.     ← much + неисч. (time)
I need access.              ← часто без a (access — неисч./абстракт)
```

### Предлоги в кусках

```text
I need English for work.
I want to deploy to production.
I need to talk about this issue.
I don’t have time in the morning.
```

- [ ] *he/she* → *wants / needs / doesn’t have*?
