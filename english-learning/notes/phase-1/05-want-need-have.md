# Theme 5 — Chunks: *want to / need to / don’t have*

Цель: стабильные куски речи без кальки с русского (*I want read*, *I need English for…* ок, но *I want free reading* — нет).

---

## 1. *want to + V* — хочу сделать

| | Пример |
|--|--------|
| ✓ | I **want to** read documentation. |
| ✓ | I **want to** improve my English. |
| ✓ | She **wants to** deploy on Friday. |
| ✗ | I want read… |
| ✗ | I want free reading… |

После *want* почти всегда **to + глагол** (инфинитив).

```text
I want to fix this bug.
Do you want to clarify the requirements?
I don’t want to postpone the release.
```

---

## 2. *need to + V* — нужно сделать

| | Пример |
|--|--------|
| ✓ | I **need to** clarify the requirements. |
| ✓ | We **need to** fix this bug. |
| ✓ | He **needs to** review the code. |
| ✗ | I need clarify… |
| ✗ | I need reading… |

*need to* = обязанность / необходимость действия.  
*need* + существительное тоже бывает: *I need English* / *I need help* — без *to*.

```text
I need English for work.           ← существительное
I need to improve my English.      ← глагол → to
We need a reliable solution.       ← существительное
We need to find a reliable solution.
```

---

## 3. *don’t / doesn’t have* — нет чего-то

| | Пример |
|--|--------|
| ✓ | I **don’t have** a clear goal. |
| ✓ | I **don’t have** much time. |
| ✓ | He **doesn’t have** access. |
| ✗ | I dont target… |
| ✗ | I haven’t a goal… *(в A2 лучше don’t have)* |

```text
I don’t have a ticket for this bug.
She doesn’t have enough experience yet.
Do you have a deadline this week? — Yes, I do. / No, I don’t.
```

---

## 4. Частые связки (выучи целиком)

```text
I want to + V
I need to + V
I don’t want to + V
I don’t need to + V
I don’t have + noun
He wants to / needs to / doesn’t have
```

Под работу:

```text
I want to read technical documentation.
I need to clarify the requirements.
I don’t have a clear estimate yet.
We need to prioritize this issue.
I want to improve my English.
```

---

## 5. Ловушки из твоих текстов

| ✗ | ✓ |
|---|---|
| I want read | I want **to** read |
| I want free reading | I want **to read** … freely |
| I need improve | I need **to** improve |
| I dont target | I **don’t have** a (clear) goal |
| I need to English | I need English / I need **to learn** English |

---

## 6. Мини-текст

```text
I am a developer. At work I develop software for traders.
I want to improve my English.
I need to read documentation every week.
Right now I need to fix a crucial bug.
I don’t have much time today.
I don’t want to postpone the deadline.
```

Следующая тема: Past Simple intro (*I worked / I developed*).
