# Assignments

Домашние и сессионные задания. Пишешь ответ **сам** в файле; ментор **не редактирует** твой блок — ниже пишет правильный вариант и комментарии.

## Структура

```text
assignments/
├── README.md          ← эти правила
├── phase-1/
├── phase-2/
└── phase-3/
```

Имена файлов: `NN-short-slug.md` (например `01-present-simple.md`).

## Формат файла задания

```markdown
# P1-01 — Present Simple (work)

| | |
|--|--|
| Phase | 1 |
| Theme | Present Simple |
| Status | todo / in_progress / done |

## Task
…инструкция…

## Your answer
…только ты пишешь сюда…

## Mentor feedback
*(заполняет ментор после проверки — твой блок выше не меняет)*
```

## Правила

1. **ПК:** ты пишешь **только** в `## Your answer` (и при необходимости отмечаешь Status → `in_progress` / просишь проверить).  
   **Телефон:** отвечаешь в чате; ментор вставляет твой текст в `## Your answer` **без правок** (режим описан в [english-learning/README.md](../README.md)).
2. Ментор **никогда** не правит текст внутри `## Your answer` (ни при ПК, ни при занесении с телефона).
3. Разбор — только в `## Mentor feedback`: исправленная версия + короткие комментарии (обычно ≤3 главных пункта) + что добавить в error bank / Anki.
4. После разбора Status → `done` (ставит ментор или ты по договорённости).
5. Ссылка на задание и итог дублируются кратко в `progress.md` (Session / Weekly log).
6. Перед заданием почти всегда есть конспект в `notes/phase-N/`. На телефоне ментор дублирует краткую теорию в чат. Вопросы по теме — в чат; устойчивые ответы — в `notes/phase-N/faq.md`.

## Статусы

| Status | Значение |
|--------|----------|
| `todo` | выдано, ещё не начал |
| `in_progress` | пишешь |
| `review` | готово к проверке ментором |
| `done` | разобрано |
