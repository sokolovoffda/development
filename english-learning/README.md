# English Learning

Личный трек изучения английского с ментором в Cursor.

Обсуждение и заметки — **на русском**. Практика письма/говорения в чате — часто **на английском** (с разбором).

---

## Два режима сессии (ПК / телефон)

Иногда учишься с **ПК**, иногда с **телефона**. Источник правды по материалам всегда файлы в `english-learning/`; меняется только *как* идёт сессия.

| | **ПК** | **Телефон** |
|--|--------|-------------|
| Теория | Читаешь note в `notes/` (или GitHub) | Ментор даёт **краткую теорию прямо в чате** (без «открой файл») |
| Задание | Читаешь `assignments/…`, пишешь в `## Your answer` | Ментор даёт задание **в чате**; ты отвечаешь **сообщением** |
| Сдача | Status → `review` + «проверь …» | Ответ в чате = сдача (можно написать «проверь») |
| После разбора | Ментор пишет `## Mentor feedback`, error bank, progress | То же: ментор **заносит** твой ответ в `## Your answer` *как есть*, feedback — по правилам ниже |

**Как выбрать режим:** в начале сессии напиши «с телефона» / «с ПК» — или ментор смотрит по контексту (mobile chat vs desktop). Можно сменить режим mid-session одной фразой.

Правила разбора **одинаковые** в обоих режимах: блок ответа не «улучшается» задним числом; правки и комментарии — только в `## Mentor feedback` (обычно ≤3 пункта) + обновление progress / error bank.

## Согласованный workflow

1. **Notes** — ментор пишет конспект темы в `notes/phase-N/` *до* или вместе с заданием (на телефоне дублирует суть в чат).
2. **Assignments** — ментор выдаёт задание в `assignments/phase-N/NN-….md` (на телефоне — текст задания ещё и в чат).
3. **ПК:** читаешь note → пишешь только в `## Your answer` → Status `review` → в чате «проверь …».  
   **Телефон:** читаешь теорию в чате → отвечаешь в чате → ментор копирует ответ в `## Your answer` без правок.
4. Ментор **не меняет** твой ответ; ниже в `## Mentor feedback` — правильный вариант + комментарии; обновляет error bank / progress / статус темы.
5. **Чат** — вопросы по ходу. Если вопрос в рамках **текущей фазы**, ментор кратко отвечает и при необходимости фиксирует в `notes/phase-N/faq.md` (или дописывает в note темы).
6. Вопросы «далеко вперёд» (другая фаза / весь английский сразу) — коротко в чате, в notes фазы не раздуваем.

Ритм слотов и лимиты (0–5 новых chunks/день и т.д.) — в [plan.md](plan.md).

## Как фиксируется прогресс (кратко)

1. **Тема** закрыта → статус в `phases/phase-N.md`.
2. **Задание** разобрано → `Mentor feedback` + Status `done`.
3. **Сессия / неделя** → `progress.md`.
4. **Ошибки** → Error bank (`open` → `review` → `done`).
5. **FAQ** по фазе → `notes/phase-N/faq.md`.
6. **Раз в ~4 недели** → Checkpoint.
7. **Конец фазы** → Exit criteria; детализируем следующий phase-файл.
