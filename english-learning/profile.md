# Learner profile

Обновлено: 2026-08-29

## Контекст

- Роль: frontend / web developer (Vue 3, TypeScript, Pinia, FSD, i18n).
- Продукт: dealing console для трейдеров в банках.
- Параллельно: заочная учёба, диплом через ~6 месяцев → нагрузка ограничена.

## Самооценка уровня

| Навык | Оценка (1–5) | Комментарий |
|-------|--------------|-------------|
| Reading | 3 | Опора на знакомые слова; грамматика мешает |
| Listening | 2 | Главная боль |
| Writing | 3 | Тех. лексика есть; формы глаголов и структура слабые |
| Speaking | 2 | Главная боль |
| Grammar | слабо | Правила «вспоминаются», не автоматизм |
| Vocabulary | относительно ок | Много слов выучено раньше; нужно повторение |

**Заявленный CEFR:** A2 (школа + самостоятельные попытки).

## Цели (3–6 месяцев)

Чёткого внешнего дедлайна нет. Рабочие цели на период:

1. **Главная:** устойчивый повседневный английский «для себя» + база технического EN (доки, промпты, UI/код-термины).
2. **Побочная:** свободнее читать короткую техдокументацию.
3. **Побочная (горизонт дальше):** говорить в поездках.

В работе пока **не** пишет и **не** читает на EN регулярно — это нужно встроить постепенно через план.

## Время и режим

| Параметр | Значение |
|----------|----------|
| Бюджет | ~**7 ч/нед** (первые ~6 месяцев) |
| Формат | Короткие сессии **ежедневно** (15–25 мин) |
| Частота | **4–5 дней** в неделю |
| Слоты | Утро ~15 мин · на работе ~15 мин · вечер 15–30 мин |
| Коммьют | Можно **говорить** (shadowing / монологи) |

## Предпочтения

- Комфортнее: **чтение и письмо**.
- Нужно целенаправленно тянуть: **listening + speaking**.
- Формат контента: нравятся ролики «сначала по-русски, потом по-английски» (билингвальные объяснения).
- Готов часто писать/отвечать **на английском** в этом чате с разбором ошибок.

## Что не зашло раньше

- Duolingo, «просто YouTube» — расфокус, нет постоянства, нет измеримого результата.

## Вывод для методики

Нужны: **фиксированный ритуал**, **маленькие измеримые победы**, **feedback в чате**, минимум «бесконечного скролла». Грамматику — через предложения и свои тексты, не через таблицы времён в вакууме. Лексику — spaced repetition коротких списков под твои темы.
