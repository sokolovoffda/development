## Exit criteria (выход из Phase 1)

Переход в Phase 2, когда **все** выполнены (или сознательно перенесены с пометкой в progress):

- [ ] Пишешь 8–10 предложений о работе в Present Simple почти без *I working / i development / On work*
- [ ] Отличаешь *I work* vs *I’m working* в 5 своих примерах
- [ ] Используешь *a/an*, *at work*, *I want to / I need to* в тексте без подсказки
- [ ] Error bank: ≥ half пунктов Phase-1 → статус `review` или `done`
- [ ] Listening: 1 короткий трек с текстом — понимаешь суть без перевода всего
- [ ] Speaking: шаблон монолога (~4 предложения) вслух без чтения с листа
- [ ] Чекпоинт Week 4 и Week 8 записаны в `progress.md`
